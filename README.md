## 📖 Project Description

This is an independent, fan-made project based on a fork of the **PCSX2** emulator, designed to simplify game access and launching through a custom launcher.

## 🚀 Launcher Scope

The launcher serves as a custom interface that makes it easier to launch and play the game through the PCSX2 emulator, providing a more convenient and accessible user experience.

Its primary purpose is to **centralize and simplify the game launch process, allowing users to start the game with a single click**, without having to manually access the emulator's interface each time.

The launcher:

- ✅ Allows users to launch the game with a single click.
- ✅ Simplifies access to the PCSX2 emulator.
- ✅ Provides a customized launch interface.
- ✅ Enhances user convenience and overall experience.
- ❌ Does not replace the PCSX2 emulator.
- ❌ Does not modify the original video game content.
- ❌ Does not constitute a native PC port of the game.
- ❌ Does not provide video games or BIOS files.

> **Note:** The launcher relies on PCSX2 and the files required for emulation to function properly.

## 📦 Repository Contents

This repository contains only the files and components necessary for the launcher to function and integrate with the emulator.

### 🚫 Content Not Included

- Game copies or ISO images.
- PlayStation 2 BIOS files.
- Proprietary files or copyrighted game content.

**Users are responsible for providing their own legally obtained game and BIOS files.**
