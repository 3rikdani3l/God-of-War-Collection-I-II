
## 📖 Descripción del proyecto

Este es un proyecto independiente desarrollado por aficionados (*fan-made*), basado en un fork del emulador **PCSX2**, cuyo propósito es simplificar el acceso y la ejecución del juego mediante un launcher personalizado.

## 🚀 Alcance del launcher

El launcher funciona como una interfaz de inicio que facilita la ejecución del juego a través del emulador PCSX2, ofreciendo una experiencia más cómoda y accesible para el usuario.

Su función principal es **centralizar y simplificar el proceso de inicio del juego, permitiendo ejecutarlo con un solo clic**, sin necesidad de acceder manualmente a la interfaz del emulador en cada ocasión.

El launcher:

- ✅ Facilita la ejecución del juego con un solo clic.
- ✅ Simplifica el acceso al emulador PCSX2.
- ✅ Proporciona una interfaz de inicio personalizada.
- ✅ Mejora la comodidad y experiencia del usuario.
- ❌ No reemplaza el emulador PCSX2.
- ❌ No modifica el contenido original del videojuego.
- ❌ No constituye una versión nativa del juego para PC.
- ❌ No proporciona videojuegos ni archivos BIOS.

> **Nota:** El funcionamiento del launcher depende de PCSX2 y de los archivos necesarios para la emulación.

## 📦 Contenido del repositorio

Este repositorio contiene exclusivamente los archivos y componentes necesarios para el funcionamiento del launcher y su integración con el emulador.

### 🚫 Contenido no incluido

- Copias de videojuegos ni imágenes ISO.
- Archivos BIOS de PlayStation 2.
- Archivos propietarios o contenido del juego protegido por derechos de autor.

**El usuario es responsable de proporcionar sus propios archivos del juego y BIOS, obtenidos de manera legítima.**
